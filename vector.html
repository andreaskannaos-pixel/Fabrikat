  1. Create an invite and send the code to your opponent.

  1. Paste the host's invite code and create a reply.
  2. Send the reply code back. The match starts when the host connects.

Room codes use the VECTOR server only to introduce the two browsers; the match then runs over a direct connection, or through the VECTOR relay when a network blocks direct connections. The copy-paste option works without any server but can fail on strict networks. Each player simulates their own field, and results are not verified by a server.
