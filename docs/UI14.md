# Start screen, customization and clean-screen logic

All code is in `index.html`, in the block headed `V14 UI`. Search for the names below.

## Event bus

`Bus.on(event, fn)` and `Bus.emit(event, data)`. The game emits these events:

| Event | Emitted when | Listener |
| --- | --- | --- |
| `stage` | the nation reaches a new stage (`stageSecond`) | +40 × stage credits |
| `mission` | a mission completes (`missionCheck`) | +15 credits |
| `milestone` | a money milestone is reached (`checkGoals`) | +10 credits |
| `unlock` | a hidden menu becomes available (`Unlocks.check`) | banner and toast |

## SaveManager

Everything is stored in `localStorage`:

| Key | Holds |
| --- | --- |
| `fabrikat-slots` | slot index: `[{id, name, date, stage, money, life, mission}]`, newest first |
| `fabrikat-slot-<id>` | one `serialize()` snapshot |
| `fabrikat-cur` | the active slot id (used after a hot reload) |
| `fabrikat-profile` | the profile (see below), shared by every slot |

- `migrate()` runs once. It moves the old `fabrikat-save-v3` save into a slot named "Your first factory", then deletes the old key.
- `save()` writes to `SaveManager.cur` only while a game is running. Autosave, `beforeunload` and tab hiding all go through it.
- There are at most 6 slots. If storage is full, you get a toast and the game keeps running.

## Title flow

```
boot ─▶ start(): profile, theme, paint, migrate
          │ hot-reload snapshot?  yes ─▶ load() ─▶ game
          ▼ no
        Title.open()  (loop idles: gameOn=false / titleCover=true)
          ├ New Game ─▶ Title.launch(null)
          ├ Continue ─▶ slot list ─▶ Load ─▶ Title.launch(id)
          ├ Shop / Editor (overlays above the title)
Title.launch: loading card ─▶ rAF + 30 ms ─▶ newGame() or load()+offlineGain()
              ─▶ gameOn, Unlocks.check(quiet), save ─▶ 2 frames rendered
              ─▶ canvas fades in, title fades out (0.45 s) ─▶ intro for new games
Menu › Main menu: save ─▶ Title.open() (Resume returns without reloading)
```

The loading card paints before the heavy work, and the first two frames are drawn under the opaque title, so the fade never shows a half-built world.

## Profile, Character Editor and shop

- The profile is `{head, body, color, pet, theme, paint, own, credits, earned}`.
- `plReset()` copies `Profile.look()` into `pl.look` when the world is generated. Saves keep `pl.look`.
- `lookOf(pl)` converts old saves, which only have an outfit, into a look.
- `drawAvatar(g, X, Y, s, look, state)` draws every head and body combination. The in-game President and the editor preview both use it.
- Paint jobs overwrite `CC` from `PAINTS[k].cc` over a copy of the defaults (`CC0`). They then rebuild the icons and blueprint previews. Machines are drawn every frame, so they recolour at once.
- Themes set `html[data-skin]`, which swaps the CSS variables and panel backgrounds.
- A pet (`drawPet`) trails behind the President and teleports back if it falls more than 12 tiles behind.

## Progressive unlocking

`UNLOCKS[k].when()` is checked every second. The first time a check passes, it sets `stats.unl[k]` and emits `unlock`. Loading a game or starting a new one runs a quiet check that sets the flags without showing banners.

| Key | Condition |
| --- | --- |
| `world` | mission 2 done |
| `cities` | a city founded (or mission 3) |
| `military` | Basic Ballistics (or Infantry) researched |
| `nations` (Diplomacy tab) | mission 5, two provinces owned, or any war |
| `naval`, `strategic` | missions 7 and 8 |

`unlockedNav(k)` returns `Unlocks.has(k)`. Locked nav buttons are not rendered at all, and the Nations tab in the World panel is hidden.

## Contextual overlays

`ctxFrame()` runs before every render and sets the `CTX` flags:

| Flag | On when |
| --- | --- |
| `recipe` | Alt held, the setting is Always, or you are holding a building |
| `fluid` | Alt held, the setting is Always, or you are holding (or have open) a pipe, pump, tank, well, chemical plant, reactor or generator |
| `stats` | Alt held, or the setting is Always |
| `hov` | set to the entity under the cursor |

- Recipe badges show when `recipe` is on, or on the hovered or open machine.
- Fluid ports follow the same rule with `fluid`. Pipe flow dots need `fluid`.
- Agent state labels and army-camp labels need `stats`. The PRESIDENT tag needs `stats` or close zoom.
- Warning icons always show.
- Alt+click no longer removes buildings. Use X or right-click.

## Contextual attack popup

- `MilitaryUnit.draw` stores a screen hit rectangle every frame. `unitAt(x, y)` accepts only rectangles drawn in the last 120 ms.
- `ctxPointer(x, y, pid)` runs on a click with no tool, in both views:
  1. a unit sprite comes first: its province (AI frontier), the target of your attack, or the source of an enemy attack
  2. then land that isn't yours
  3. your own land opens the normal province panel
- The popup (`#ctxpop`) shows the owner, war state, defense, your free force and army size. Its actions:
  - **Declare war** (two-step confirm) → `declareWar`
  - **Attack · half / all** → `playerAttack(p, .5 | 1)`. It explains when the land isn't adjacent or you have no troops.
  - **Buy** → `buyProv` (neutral land next to yours)
  - **Details** → `openProv`
- Escape, or another click on the map, closes it.
